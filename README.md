# Praktikum Python

Proyek ini dibuat untuk praktikum Python menggunakan VS Code, virtual environment, dan Git.

## Fitur
- Menampilkan sapaan kepada pengguna.
- Menghitung perkiraan usia berdasarkan tahun lahir.
- Menampilkan tabel alat praktikum menggunakan paket Rich.

## Cara Menjalankan
1. Aktifkan virtual environment.
2. Instal paket dengan `pip install -r requirements.txt`.
3. Jalankan program sapaan dengan `python halo.py`.
4. Jalankan tabel alat dengan `python tampil.py`.
